ADR-001 | 2026-09-09 | Accepted

Context:
We need an architecture for NexFlow that delivers instantaneous, offline-capable goal workflow generation, integration mapping, cost calculation, and redundancy detection.

Decision:
Implement a deterministic client-side domain engine with a rich local catalog of software tools and goal templates, backed by reactive Next.js/React state management.

Alternatives Considered:
1. External LLM API calls on every recommendation query: Rejected due to API cost, network latency, non-deterministic output, and risk of hallucinating invalid tool integrations.
2. Server-side SQL database with REST API endpoints: Deferred for MVP as local-first structured catalog achieves offline speed and lower operational complexity.

Consequences:
Fast, instantaneous user experience with 0 API key dependencies and zero hosting database costs for MVP.
